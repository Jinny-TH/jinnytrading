# Jinny Trading v31

## 변경 내용
- 종목별 누적 배당을 `ticker` 기준으로 합산합니다.
- 같은 종목의 월별 배당 기록 또는 account_id가 비어 있는 과거 기록이 한 줄로 합쳐집니다.
- 전체 계좌에서 같은 종목이 여러 계좌에 있으면 계좌명은 `여러 계좌`로 표시됩니다.
- 기존 월별 배당 아코디언, 개별 종목 배당률, 추가매수 기능은 유지됩니다.

## SQL
추가 SQL은 필요하지 않습니다.

## v32 일별 자산 추이 개선
- 차트 화면에는 최근 14일 분량이 보이도록 막대 폭과 차트 너비를 조정했습니다.
- 과거 전체 기록은 가로 스크롤 또는 좌우 이동 버튼으로 확인할 수 있습니다.
- 차트가 열릴 때 가장 최근 날짜가 보이도록 오른쪽 끝으로 자동 이동합니다.
- 막대 위 금액을 `2.05억`, `8,234.50만`처럼 소수점 둘째 자리까지 표시합니다.
- DB/SQL 변경은 없습니다.
