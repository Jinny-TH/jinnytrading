# Jinny Trading v30

## 변경 내용
- 배당 현황 화면에 종목별 누적 배당금 표시
- 누적 배당금 기준 내림차순 정렬
- 종목별 누적 배당 비중(%) 표시
- 가로 Progress Bar로 시각화
- 기본 상위 5개 표시 및 전체보기/접기 지원
- 전체 계좌/개별 계좌 필터와 자동 연동
- 기존 월별 배당 아코디언 및 종목별 배당률 표시 유지

## DB 변경
추가 SQL은 없습니다.

## 빌드 확인
현재 실행 환경의 npm 레지스트리에서 `@supabase/supabase-js` 패키지를 찾지 못해 의존성 설치 및 `next build` 검증은 완료하지 못했습니다.
